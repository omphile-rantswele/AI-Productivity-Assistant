# AI-Powered Workplace Productivity Assistant

## Project Overview

The AI-Powered Workplace Productivity Assistant is a web-based application designed to help professionals automate repetitive workplace tasks using Artificial Intelligence. The platform improves productivity by assisting users with email generation, meeting note summarization, task planning, research support, and conversational workplace assistance.

This solution addresses common workplace challenges where employees spend significant time drafting communications, organizing tasks, reviewing lengthy documents, and conducting research. By leveraging AI, the application reduces manual effort, improves efficiency, and enables users to focus on higher-value activities.

---

## Features

### 1. Smart Email Generator

Generate professional emails based on:

* Email purpose
* Audience type (Client, Manager, Team Member, Supplier)
* Preferred tone (Formal, Friendly, Persuasive, Professional)

Outputs:

* Subject line
* Professional email content
* Recommended call-to-action

### 2. Meeting Notes Summarizer

Transform lengthy meeting notes into concise summaries.

Outputs:

* Executive summary
* Key discussion points
* Decisions made
* Action items
* Responsibilities and deadlines

### 3. AI Task Planner

Organize and prioritize tasks automatically.

Features:

* Daily planning
* Weekly scheduling
* Priority management
* Time optimization recommendations
* Productivity suggestions

### 4. AI Research Assistant

Analyze and summarize information from articles, reports, and business topics.

Outputs:

* Key insights
* Summary reports
* Opportunities and risks
* Actionable recommendations

### 5. AI Workplace Chat Assistant

Interactive chatbot that provides:

* Workplace guidance
* Content drafting assistance
* Productivity recommendations
* General AI-powered support

### Additional Features

* Dark and Light Mode
* Analytics Dashboard
* Export to PDF
* Prompt Library
* Productivity Tracking
* AI Transparency and Disclaimer Section
* Mobile Responsive Design

## Setup Instructions

### Prerequisites

Ensure the following are installed:

* Node.js (v18 or later)
* npm or yarn
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/your-repository/ai-productivity-assistant.git
```

Navigate to the project folder:

```bash
cd ai-productivity-assistant
```

Install dependencies:

```bash
npm install
```

or

```bash
yarn install
```

### Environment Variables

Create a `.env` file in the project root:

```env
VITE_OPENAI_API_KEY=your_openai_api_key
```

### Run Development Server

```bash
npm run dev
```

or

```bash
yarn dev
```

Open your browser:

```text
http://localhost:5173
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Responsible AI

This application follows responsible AI principles:

* AI-generated outputs should be reviewed by users.
* Sensitive information should not be shared with AI systems.
* Users should validate critical decisions before implementation.
* The system includes transparency notices regarding AI limitations and potential inaccuracies.
